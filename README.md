# AI-Enabled Women Safety Risk Mapping and Predictive Alert System

## Project Overview
This project is a web-based safety risk prediction system developed using Python Flask and Machine Learning. It helps users explore estimated safety risk levels across selected areas of Mumbai and provides features for incident reporting and route comparison.

## Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: Python Flask
- Database: SQLite3
- Machine Learning: Scikit-learn, Pandas, Joblib
- Development Environment: Visual Studio Code

## Main Features
- User Registration and Login
- Safety Risk Prediction
- Interactive Safety Map
- Compare Routes
- Incident Reporting
- SOS Interface
- Admin Dashboard

## How to Run the Project
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Create and activate a Python virtual environment.
4. Install the required Python libraries using `pip install -r requirements.txt`.
5. Initialize the SQLite database using the project's setup instructions.
6. Run the Flask application using `python app.py`.
7. Open `http://127.0.0.1:5000` in a web browser.

## Important Limitations
The system uses a limited dataset for safety risk prediction. Predictions are estimates and do not guarantee personal safety. The project should not replace official emergency services.
